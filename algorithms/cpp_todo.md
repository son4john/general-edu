# C++ Things to Try

- [ ] **Templates** — write a generic `max()` / `Stack<T>`, then try a variadic template.
- [ ] **Building** — move a `.cpp` file to a real build: `g++` by hand, then a `Makefile`, then `CMakeLists.txt`.
- [ ] **A server** — raw TCP echo server with POSIX sockets (`socket`/`bind`/`listen`/`accept`).
- [ ] **Multi-threading** — `std::thread` + `std::mutex` producer/consumer queue.
- [ ] **Binary data packets** — define a packed struct header, `memcpy` into a `char` buffer, watch out for endianness/alignment.
