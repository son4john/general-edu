# Kalman Filter Demo

A small, self-contained educational demo of a 1D Kalman filter tracking a car's position from noisy GPS readings.

## Scenario

A car drives in a straight line at a constant velocity. A GPS sensor reports the car's position, but each reading is noisy (true position + random error). The Kalman filter fuses this noisy measurement with a simple motion model ("the car keeps moving at roughly the same speed") to produce a smoother, more accurate position estimate — along with a running estimate of how confident it is.

State vector: `x = [position, velocity]`
Measurement: `z = [position]` (GPS only observes position, not velocity)

## Files

| File | Description |
|---|---|
| `kalman_demo.py` | Simulates the car and GPS noise, runs the Kalman filter, plots the results, and prints an error summary. |
| `kalman_demo.png` | Output plot generated by the script. |
| `kalman_demo.txt` | Plain-English explanation of the scenario, the plots, and the filter's core matrices. |

## Running it

```bash
python kalman_demo.py
```

Requires `numpy` and `matplotlib`. This regenerates `kalman_demo.png` and prints a comparison of raw GPS error vs. filtered error to the console.

## The filter cycle

Each time step runs two steps:

1. **Predict** — project the state forward using the motion model (`F`), and grow the uncertainty (`P`) to reflect that time has passed.
2. **Update** — compare the prediction to the new noisy measurement, compute the Kalman gain (`K`) — how much to trust the measurement vs. the prediction — and blend the two. Uncertainty shrinks accordingly.

The Kalman gain is the heart of the filter: if the sensor is very noisy, the filter leans on the motion model; if the model is uncertain, it leans on the sensor. This weighting is recomputed every step.

## Key matrices

| Matrix | Meaning |
|---|---|
| `F` | State transition matrix — how the state evolves over time (position advances by velocity·dt; velocity stays constant) |
| `H` | Measurement matrix — maps state to what the sensor observes (position only) |
| `Q` | Process noise covariance — how much we trust the motion model |
| `R` | Measurement noise covariance — how noisy the GPS sensor is |
| `K` | Kalman gain — computed each step; balances prediction vs. measurement |
| `P` | Error covariance — the filter's current uncertainty about the state |

## Output

The script produces a two-panel plot:

- **Top — Position over time**: true position (green), raw noisy GPS readings (red dots), and the Kalman estimate (blue) with a ±2σ uncertainty band.
- **Bottom — Uncertainty over time**: starts high, drops sharply as measurements arrive, then plateaus once process noise (rather than lack of data) becomes the limiting factor.

See `kalman_demo.txt` for a more detailed walkthrough of these plots and concepts.
